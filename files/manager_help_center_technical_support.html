Technical FAQ

How do I reset biometric sensor calibration? expand_more
Access the System Admin panel, navigate to Node Calibration, and select 'Hard Reset'. Ensure the physical sensor is clear of debris before initializing.
Network latency is exceeding 50ms in Zone B. expand_more
This usually indicates interference or heavy traffic on the 6GHz band. Try switching the Zone B router to 'Isolated Mode' for critical operations.
How to provision new manager credentials? expand_more
Only System Admins can provision credentials. Go to System Admin > User Roles > New Provisioning and follow the encrypted onboarding flow.
