Node Troubleshooting

Why is Node #42 showing 'Limited Connectivity'? expand_more
This typically indicates a mesh network interference. Check if the physical node is obstructed by recent campus construction or if the battery level is below 15%. If the issue persists, perform a soft reset via the System Admin panel.
How often should node sensors be recalibrated? expand_more
Recalibration occurs automatically every 30 days during low-traffic hours (02:00 - 04:00). Manual recalibration is only required after a high-impact weather event or physical tampering.

User Management

How do I revoke temporary access for visiting staff? expand_more
Navigate to System Admin > Access Control. Select the staff member and click 'Terminate Session' or adjust the 'Access Expiry' timestamp. Changes take effect across all campus nodes within 60 seconds.
What is the maximum number of concurrent managers? expand_more
Guardian Shield supports up to 15 concurrent Administrative Managers per campus zone. If you reach this limit, users will be placed in a view-only queue until a session slot opens.

Emergency Protocols

What happens when the 'Red Alert' state is triggered? expand_more
A Red Alert triggers immediate haptic feedback for all security personnel, pushes a high-priority notification to local law enforcement, and engages the 'Safe-Path' visual indicators on all physical campus nodes.
